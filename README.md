# Elevate-Responsiveness
A basic landing page for a  cleaning business for advertisement

<h1>Palmacedar Cleaning Services</h1>
<p>The landing page is a simple one-page website built with plain HTML and CSS, with no JavaScript, in a white, blue and red color scheme. The header holds a circular logo and nav links, which sit in a row on desktop using Flexbox and collapse into a hamburger drop down on phones. </p>
<p>  The hero uses a one-cell CSS Grid so the heading, tagline and button overlay the image, with a dark gradient keeping the text readable. Below it are three feature cards (Innovation, Quick and Fast, Quality) 
 that sit in a responsive grid built with repeat(auto-fit, minmax ( 260px, 1fr). They go from a row to two columns to a single column as the screen gets smaller with each having its own SVG icon.</p>
